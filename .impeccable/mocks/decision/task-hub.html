A first history query

A bounded block range keeps the request specific.

cURLJavaScriptGET
# Replace HYPERION_URL with your provider
curl --get "$HYPERION_URL/v2/history/get_actions" \
  --data-urlencode "filter=eosio.token:transfer" \
  --data-urlencode "block_num=100000-100100" \
  --data-urlencode "limit=10"
