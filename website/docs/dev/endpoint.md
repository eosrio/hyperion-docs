# Hyperion provider directory

Use these provider-managed links to discover an API for your chain. Confirm chain identity, indexed range and enabled capabilities with its operator before depending on it. Directory membership is not a live availability or coverage guarantee.

Strip a trailing `/v2` when configuring a client that expects the API base URL. Query `/v2/health` and inspect the provider API specification to verify the selected service.

!!!tip
    Check the endpoint status at [https://bloks.io/hyperion](https://bloks.io/hyperion)
