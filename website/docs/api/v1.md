## Provider-specific operations

Inspect `/docs` or `/v2/docs` on the running provider. `/v1/node/get_supported_apis` merges core and upstream-node capabilities. The `/v1/chain/*` wildcard is forwarded; the upstream node owns its complete request/response contract.
